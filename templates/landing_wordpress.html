Qué comprueba esta auditoría

ReconBase analiza tu WordPress desde fuera, como lo haría un atacante. En 60 segundos te entrega el siguiente desglose:

✓
Versión del coreDetección por meta, RSS, wp-json y readme.html. Comparación con la última versión estable.
✓
Plugins vulnerablesCruce contra lista de plugins con CVE conocidos: WP File Manager, Duplicator, Elementor antigua, etc.
✓
xmlrpc.php expuestoVector clásico de fuerza bruta y pingback DDoS. Comprobamos si responde con XML-RPC.
✓
Usuarios enumerablesComprobamos /wp-json/wp/v2/users — si está abierto, cualquiera ve los nombres de admins.
✓
Archivos sensiblesBackups expuestos (wp-config.php.bak, ~), install.php accesible, debug.log público.
✓
Tema activoIdentificamos el theme para detectar versiones desactualizadas con problemas conocidos.

Por qué importa

El 43% de WordPress hackeados es por plugins desactualizados (Sucuri Security Report 2025). La mayoría de pymes españolas usan WordPress sin nadie que lo mantenga: instalación inicial, abandono y descubrimiento del problema solo cuando ya es tarde — emails de Google avisando de malware, hosting que cierra la cuenta, clientes que dejan de entrar porque el navegador marca tu web como insegura.

La auditoría gratuita de ReconBase no resuelve el problema por ti, pero te da el mapa: qué hay roto, qué nivel de urgencia tiene y por dónde empezar. Si te asusta lo que ves, créate cuenta y recibe el informe ejecutivo en PDF con el plan de acción priorizado.

Preguntas frecuentes

¿Es seguro escanear mi WordPress?
Sí. Solo hacemos peticiones HTTP públicas, las mismas que cualquier visitante de tu web. No nos conectamos a tu wp-admin, no requerimos credenciales y no modificamos nada. Es análisis pasivo y RGPD-compliant.
¿Cuántos chequeos lanzáis?
Más de 20 entre el escáner web general y el módulo WordPress: puertos, SSL, DNS, cabeceras, plugins, archivos sensibles, filtraciones de credenciales asociadas al dominio, etc.
¿Detectáis malware en mi WordPress?
Comprobamos si tu dominio aparece en blocklists de Google Safe Browsing y Norton Safe Web (la señal definitiva de malware activo). Para escaneo profundo de archivos PHP internos, usa Wordfence o Sucuri SiteCheck además de ReconBase.
¿Y si mi WordPress está bien protegido?
Mejor — la auditoría te lo confirma con un informe limpio que puedes usar como evidencia de "due diligence" (útil para RGPD y NIS2).
