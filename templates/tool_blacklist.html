Consultamos las listas de Google; no nos conectamos a tu web. Al usar la herramienta aceptas los Términos.

Qué significa estar en una lista negra

Cuando un servicio de seguridad detecta que tu web distribuye malware o aloja una página de phishing, te añade a su lista negra (blocklist). A partir de ese momento:

• Muchos navegadores muestran una advertencia ("El sitio que intentas visitar puede ser peligroso") antes de dejar entrar a tus visitantes.

• Los resultados de búsqueda de Google pueden mostrar un aviso junto a tu web.

• Algunos filtros de correo y antivirus pueden bloquear los enlaces a tu dominio.

El resultado: buena parte de tus visitantes deja de llegar aunque la web siga funcionando.

Qué fuentes consultamos

Google Web Risk: el servicio de Google para empresas que permite consultar sus listas de sitios con malware, phishing o software no deseado. Ninguna lista detecta todos los sitios peligrosos, así que un resultado limpio no garantiza que la web lo esté.

Si tu web está listada, qué hacer

Estar en una lista negra es síntoma de que tu web fue comprometida. El orden de actuación:

1. Limpia el origen. No sirve de nada pedir la revisión si el malware sigue ahí. Identifica y elimina el código malicioso (o restaura desde un backup limpio). Nuestra auditoría completa y la de WordPress ayudan a localizar el punto de entrada.

2. Solicita la revisión en Google Search Console → Seguridad y acciones manuales. Google vuelve a revisar la web y, si está limpia, retira la advertencia (suele tardar unos días).

3. Vigila que no vuelva. Si no se cierra la vulnerabilidad por la que entraron, la web puede volver a infectarse.

Preguntas frecuentes

Mi web sale limpia, ¿estoy 100% seguro?
Salir limpio es buena señal, pero las listas negras reaccionan DESPUÉS de detectar el problema. Si tu web fue comprometida hace pocas horas, puede que aún no esté listada. Combina esta comprobación con una auditoría completa que detecte el problema en origen.
¿Cada cuánto se actualizan las listas?
Google las actualiza de forma continua, así que una web puede pasar de limpia a listada en poco tiempo tras un ataque.
¿Esto arregla el problema?
No, solo te dice si estás listado. Para salir de la lista tienes que limpiar la web y pedir la revisión. Esta herramienta es la señal de alarma; la auditoría completa te ayuda a encontrar la causa.
